## Project Goal
Jackpot-Therapy aims to provide a safe and controlled gambling simulation that suorts rehabilitation and therapy for individuals with gambling addiction. The aplication will serve as a tapering tool to reduce withdrawl symptoms by providing a realistic, consequence-free environment to practice self-control. 

## Project Objectives
- Complete a functional slot machine UI with smooth gameplay, animations, and sound effects by the end of Sprint 3.
- Implement the core game logic and API to handle random spin results, balance updates, and game flow by Sprint 4.
- Create a loan and payback system that allows users to take fictional loans and reay them with interest, including lose conditions, by Sprint 4.
- Develop user rofiles and high score tracking so multiple users can save progress and view personal statistics by Spring  4. 
- Deliever a working MVP that runs locally in a browser and includes documentation, by the end of the semester. 
  
## Project Scope
The project will include development of a slot machine web application that allows users to play, track their balance, take fictional loans, and save progress using user profiles. The project will also include a high score leaderboard and customizable avaters. 

**Out of scope / excluded:**
- Real-money gambling
- Real finacial transactions
- Third-party payment systems
- Advanced security beyond basic password encryption
- Anything not required for educational use
